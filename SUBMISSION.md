# ML Inference API Project – [Farid Hasan]

**GitHub Repository:**
https://github.com/faridhasan2020/Project-05/iris-api

**Model Used:**
Scikit-learn pipeline (StandardScaler + Logistic Regression) trained on the Iris dataset.
Prediction task: multi-class classification of Iris flower species (setosa, versicolor, virginica) from sepal length, sepal width, petal length and petal width.

**API Endpoints:**
- GET / – API name and description
- GET /health – Health status
- POST /predict – Predicted species with probability
